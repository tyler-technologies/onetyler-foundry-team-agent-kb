**Q:**

> How do i get a list of workspaces for an organization using the api?

**A:**

```markdown
Based on the documentation, there isn't a publicly available REST API endpoint to programmatically retrieve a list of workspaces for an organization. 

## What workspaces represent
In the Tyler Cloud Platform (TCP), workspaces are sub-tenants under an organization that typically represent different environments like "test", "stage", and "production". The production workspace key usually equals the organization key, while non-production workspaces use suffixes.

## How to manage workspaces

**For Tyler internal teams:**
- Workspaces are managed through **Ops Center** (OC), which is an internal Tyler tool
- Standard workspace suffixes are: `test`, `train`, `staging`, `dev`, `uat`, `impl`
- Non-standard workspaces require a special request through the [service desk](https://help.center.tylertech.com/servicedesk/customer/portal/3168/group/3333/create/7513)

## How applications work with workspaces

Instead of listing workspaces, applications typically:

1. **Pass workspace context during login** - Include `workspaceKey` parameter when redirecting to the `/authorize` endpoint
2. **Receive workspace in tokens** - The `workspaceKey` claim appears in ID tokens and as a scope pattern `wks:<workspaceKey>` in access tokens

For more information on login context, see the [Identity Workforce documentation](https://docs.tylerdev.io/identity).

If you need to manage or query workspaces programmatically, you'll need to submit a request through the [TCP service desk](https://help.center.tylertech.com/servicedesk/customer/portal/3168).
```
