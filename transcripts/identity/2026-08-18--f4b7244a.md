> Do we have anyting documented around 3rd party CCF integration?

**A:**

```markdown
Yes! We have documentation about **Client Credentials Flow (CCF)** integration, which is used for third-party service-to-service communication.

## Quick Overview

CCF is used when your backend services need to communicate with other APIs **without a user context**. It's ideal for:
- Backend API to API communication
- Scheduled jobs and batch processes
- Service accounts (applications acting on their own behalf)
- System-to-system integration

**Important:** Don't use CCF for user-facing authentication or when you need user identity/organizationKey context.

## Technical Details

**How many CCF clients do you need?**
1. **Multi-tenant cloud product**: Only 1 CCF client per product
2. **Cloud product deployed per customer**: 1 CCF client per customer/environment
3. **On-premise**: 1 client per product per environment (recommended)

**Key characteristics of CCF tokens:**
- No user context (no `organizationKey`, `preferred_username`, or user-specific claims)
- Token lifetime: 1 hour
- Recommended scope: Use product-specific scopes or the platform scope `tyler-cloud-platform-api-access`

**Basic token request:**
```http
POST https://idgw.tcpci.com/tg/oauth2/token
grant_type=client_credentials
&client_id={your_ccf_client_id}
&client_secret={your_ccf_client_secret}
&scope={your_api_scope}
```

You can find more details in the [Tyler Identity Knowledge Base](/api/tenant-knowledge-base/collections/TCP-KB-Identity/files/01546ed8-be5a-4cf1-ba40-0ab86a8c7dc9/download), including code examples and API security configuration.

Is there a specific aspect of CCF integration you'd like to explore further?
```
