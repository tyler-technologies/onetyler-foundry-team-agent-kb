**Q:**

> What is "Workforce User Created"

**A:**

```markdown
**"Workforce User Created"** is an event that gets published when a new workforce user is created in the Tyler Identity platform.

In simple terms: It's a notification that tells your application "Hey, a new employee/staff user account was just created!" This happens when someone creates a new workforce user through either the Admin Center or Ops Center.

## Technical Details

**Event Type:** `workforce-user-created`

**When it's triggered:** When a new workforce user is created via Admin Center or Ops Center

**Important Note:** These workforce events are only published for organizations using **Workforce Direct**.

**Example Payload:**
```json
{
  "messageType": "workforce-user-created",
  "sub": "5xieRMfpq3ha7Z8PjIoTD8tS",
  "organizationKey": "mycivicid",
  "username": "test.two@mycivicid.com",
  "givenName": "Test",
  "familyName": "Two",
  "email": "test.two@mycivicid.com"
}
```

The event includes key information about the new user like their unique identifier (sub), organization, username, name, and email address. Your application can subscribe to this event to automatically respond when new workforce users are created - for example, to provision resources or set up initial configurations for that user.

For more information about Identity events, check out the [Identity Events documentation](https://docs.tylerdev.io/identity/shared/events).
```
