**Q:**

> Is there any documentation around JIT provisioning?

**A:**

```markdown
Yes! I found documentation on JIT (Just-In-Time) provisioning in the Identity platform.

**In simple terms:** JIT provisioning is the process of automatically creating or updating user accounts in your application the first time someone logs in through Tyler Identity. Instead of pre-creating all user accounts, you create them "just in time" when they authenticate.

**The flow works like this:**

1. **First check:** Does the user's `sub` (subject identifier) match an existing user in your application?
   - **Yes** → Update their profile and username from the ID token
   
2. **Second check:** If not, does the username match an existing user with the same `organizationKey`?
   - **Yes** → Update the user's `sub` in your application, then update their profile
   
3. **Third option:** Does your application have an onboarding process for brand new users?
   - This is where you'd create a new user account

This pattern ensures users are automatically synchronized between Tyler Identity and your application without manual account setup.

You can find more details about this and other authentication patterns in the Identity documentation at: **https://docs.tylerdev.io/identity**

Would you like more specific implementation details or code examples for JIT provisioning?
```
