**Q:**

> explain Tyler Identity

**A:**

```markdown
**Tyler Identity** is Tyler's Single Sign-On (SSO) authentication platform that provides secure access to Tyler products. It offers two distinct solutions designed for different types of users:

## Two Integration Paths

**1. Identity Workforce** — for employees and back-office staff
- Connects Tyler applications directly to your organization's existing Identity Provider (like Microsoft Entra ID, Google Workspace, or Ping)
- Uses the **Identity Gateway** as a central authentication hub
- Your organization maintains full control of user identities
- Best for administrative, enterprise, and employee-facing applications

**2. Community Access** — for citizens and the public
- Single Tyler-managed system with branded login pages
- Allows self-service registration for residents and citizens
- Provides a consistent identity across all Tyler public-facing applications
- Best for citizen portals and public-facing services

## How It Works

Both solutions are built on the **OpenID Connect (OIDC)** standard. The Identity Gateway acts as the central authority that:
- Issues and validates security tokens
- Routes authentication requests to the right identity provider
- Manages user sessions across Tyler applications
- Handles the technical complexity of connecting to different identity systems

## Key Benefits

- **Single Sign-On**: Users log in once and access multiple Tyler applications
- **Security**: Built on industry-standard protocols with zero-trust architecture
- **Flexibility**: Works with your existing identity infrastructure
- **Simplified Integration**: One connection point for all Tyler workforce applications

For detailed implementation guidance, visit the [Tyler Identity documentation](https://docs.tylerdev.io/identity).
```
