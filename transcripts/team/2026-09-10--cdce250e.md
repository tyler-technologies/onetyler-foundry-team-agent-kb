Based on today's date (**September 10, 2026**) and the quarterly release schedule, here's what you need to know:

## Release Window Schedule

Aligned Releases follows a **quarterly cadence** with releases in:
- **February** (Q1 - named YYYY.1)
- **May** (Q2 - named YYYY.2)
- **August** (Q3 - named YYYY.3)
- **November** (Q4 - named YYYY.4)

## Next Release Window

The **next release window is November 2026** (release 2026.4).

Since we're currently in September, the August 2026 release (2026.3) has already occurred, making November the next quarterly window.

## How GA Rollout Works

Each quarterly release has **four cohorts** that activate across four consecutive weeks:
- **Cohort 1** = GA date (first week)
- **Cohort 2** = 1 week later
- **Cohort 3** = 2 weeks later  
- **Cohort 4** = 3 weeks later

Clients receive notifications:
- **4 weeks before Cohort 1's date** — "Your next quarterly release is coming" (sent to ALL clients regardless of their cohort)
- **The day before each activation window** — "This workspace is going to be upgraded tomorrow"

## Important Note

The specific dates for the November 2026 cohort windows (which week of November each cohort activates) would be defined by the internal OneTyler team when they create the release and its cohorts. If you need those exact dates, you would query the Aligned Releases API or check Release Manager.
