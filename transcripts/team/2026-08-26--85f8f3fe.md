## Creating an Internal Organization

There are two ways to create an internal organization, depending on your access level:

### Through the Ops Center UI

1. **Access the wizard** — From the Organizations list page, click **+Create internal**
   - Note: This option is permission-gated. If you don't see it, you'll need to request access (see the ticket catalog in `Conf-OneTylerTickets.md` for the proper form)

2. **Select Identity Setup** — Choose your identity configuration:
   - **Workforce Direct** (typical choice for most internal orgs)
   - **Workforce Delegated** (for special cases like a group/division with an IdP for internal demo users plus dependent internal orgs)

3. **Enter Org Key + Org Title** — Manually enter both fields:
   - **Org Key format**: `{3-char division/group code}{purpose code}{label}` (max 50 characters)
   - Follow internal-org naming conventions as documented in Confluence

4. **(Workforce Delegated only) Select Super org** — If using Workforce Delegated, choose a valid existing internal org that is not itself Workforce Delegated

5. **Org Admin + magic link** — Enter the Tyler staff or demo user contact information:
   - Select **"Send magic link on org creation"** to email them a federation-setup link
   - Or select **"Skip Org Admin setup"** to add them later

6. **Review summary, Save & close** — The org is created and the **production workspace is automatically created**

### Through the API

**Endpoint**: `POST /api/v2/Organization`

**Required permissions**: 
- `create:organization` AND
- `manage:internalorganization`

**Required fields**:
- `customerId`
- `name`
- `isInternal: true`

**Important limitations**:
- **Workforce Managed identity type is NOT API-provisionable** — it requires a OneTyler Support ticket with strong business justification
