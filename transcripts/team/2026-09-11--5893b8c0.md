## How to Add an Org Admin

There are **three different paths** depending on your situation:

### **Path 1: If you already have self-promotion permission**
If you already hold the self-promotion permission, you can add yourself as an Org Admin directly in the product:
- Navigate to **Organization Details > Admins** in Ops Center
- Use the self-promote action (no request required)

### **Path 2: One-off request (most common)**
If you need to add an Org Admin or self-promote and don't have the permission:
- Submit a ticket using the **"Add an Org Admin, or self-promote as Org Admin"** flow
- This is the appropriate route for occasional requests

### **Path 3: During organization creation**
When creating a new organization in Ops Center:
1. Go to the **Import wizard** or **Create Internal wizard**
2. You can optionally specify an initial Org Admin (`OrgAdminConfiguration`) during creation
3. Alternatively, you can add admins later through the dedicated Site Administrator endpoints or through **Organization Details > Admins**

### **After an organization is already created:**
1. Navigate to the organization in Ops Center
2. Open **Organization Details**
3. Go to **Organization Details > Admins**
4. Add an Org Admin (you can use the **"Use as technical contact"** option)

**Note:** The first Org Admin's userid domain is automatically set as the org domain if no domain exists yet.
