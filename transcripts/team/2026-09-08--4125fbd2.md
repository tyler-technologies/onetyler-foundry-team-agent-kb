## Adding Yourself as an Org Admin

The process depends on your role and permissions:

### If You Have Self-Promotion Permissions

If you're a select Ops user whose role requires routine customer access, OneTyler provides elevated permissions to **promote/remove yourself as an Org Admin** quickly. You can do this directly in Ops Center without filing a ticket.

### If You Need Self-Promotion Permission

If you don't already have self-promotion permissions but need them:

1. **Follow the manager's guide procedure** - There is NO generic ticket form for this
2. Your manager can grant you self-promotion permissions if:
   - You already have Ops Center access
   - You don't already have self-promotion permissions
   - Your role justifies routine customer access

### Standard Process for Org Admin Access

For the detailed procedure, refer to the **manager's guide**:
- **Confluence:** *Tyler Cloud Platform (TCP) | Org Admin promotions (Admin Center access) - a Manager's guide* (`/wiki/spaces/TTI/pages/386629479/`)

### Important Notes

- **Do NOT use** the generic "Ops Center additional permissions" form (ticket 4133) for this request
- Once you have Org Admin rights, you can access the organization's **Admin Center**
- **Tyler Tech Org Admins** can remove their own Org Admin rights when they no longer need access (please clean up after yourself!)
- Permission changes may take a small amount of time to propagate
