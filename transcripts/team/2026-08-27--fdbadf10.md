I'd be happy to help you get Tyler Identity configured! Let me search for the specific configuration steps you'll need.When Tyler Identity is enabled but not yet configured, you need to set up the Identity Provider (IdP) connection. The specific configuration steps depend on which type of Identity solution you're using:

## For **Identity Workforce** (Employee/Back-Office Applications):

The IdP configuration is managed through **Admin Center**. You need to:

1. **Configure the IdP in Admin Center** for the organization
2. **Verify the IdP metadata URL** is accessible
3. **Confirm the organization is enabled** for the appropriate mode (Workforce Direct, Managed, or Delegated)
4. **Configure required attributes/claims** in the IdP:
   - Email
   - Username
   - First name / Last name
5. **Ensure the IdP certificate is current**

The Identity Gateway acts as the central authority and routes authentication requests to the customer's IdP. The Gateway needs to know how to reach the customer's identity provider.

## For **Community Access** (Citizen/Public-Facing Applications):

Community Access uses Tyler's managed Okta tenant, so configuration is typically handled through the provisioning process.

## Next Steps to Configure:

To get Identity properly configured, you should:

- **Submit an Identity ticket** through the [Tyler Help Center](https://help.center.tylertech.com/servicedesk/customer/portal/3168/group/3329/create/4153) if you need assistance with IdP configuration
- **Check Admin Center** for your organization to see if IdP settings need to be completed
- **Verify your organizationKey** is correct and the organization exists in Ops Center
- **Ensure your IdP metadata** (SAML metadata URL or OIDC discovery endpoint) is publicly accessible

You can find detailed configuration steps in the [Identity Workforce Getting Started guide](https://docs.tylerdev.io/identity).

**Which type of Identity are you working with - Workforce (employees) or Community Access (citizens)?** I can provide more specific configuration guidance based on your scenario.
