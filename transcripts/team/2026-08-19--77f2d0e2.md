## Overview

Identity is Tyler's cloud authentication solution that enables **Single Sign-On (SSO)** across Tyler products. It allows users to authenticate once with one set of credentials and access multiple Tyler solutions.

## Two Main Types

**1. Identity Workforce** - For back-office/employee users:
- **Workforce Managed**: Tyler manages an Okta tenant for your organization's user authentication
- **Workforce Direct**: You use your own Identity Provider (IdP) like ADFS, Azure AD, Google Cloud Identity, or Okta - Tyler's preferred option

**2. Identity Community** - For public-facing/citizen users who access community services

## How Authentication Works

**For Workforce Users:**
- **Local users**: Credentials stored in Tyler-managed Okta (Workforce Managed only)
- **Federated users**: Authenticated through your external IdP via federation
- Uses **OAuth 2.0** and **JWT Bearer [redacted-token]** for secure authentication
- Supports **MFA** (Multi-Factor Authentication) for added security

**Key Components:**
- **Tyler Identity Gateway**: Handles OAuth 2.0 authentication flows
- **Session Management**: Controls how long users stay logged in
- **Password Policies**: Configurable for local users (managed in IDP for federated users)

For more detailed information about Identity configuration, authentication protocols, and implementation, I recommend checking the **Tyler Identity Implementation Assistant** at: https://docs.tylerdev.io/identity
