## How to Add a New Org Email Domain

To add an email domain to an organization in Ops Center, you need to add or update a **Technical Contact** with that domain:

### Steps:

1. **Navigate to Organization Details**
   - Go to the organization in Ops Center
   - Open the **Organization Details** page

2. **Use the Admins Section**
   - Go to **Organization Details > Admins**
   - When adding an Org Admin, use the **"Use as technical contact"** option

3. **Set the Domain**
   - When you add an Org Admin as a technical contact, their **userid domain is automatically set as the org domain**

### Important Notes:

- This is especially relevant for **organizations that were automatically created** from sales-enabled CRM records, as these auto-created orgs **do not have customer contact information or domains set** by default.

- The technical contact's email domain becomes the organization's email domain when you use the "Use as technical contact" option.

- For **Workforce Delegated** orgs: adding an Org Admin to a Sub org automatically adds the user to the Super org if not already present.
