## How to Request Organization Keys and Workspace Keys

**Organization keys** and **workspace keys** are unique identifiers used by Tyler's Identity platform to route authentication requests properly. Here's how to obtain them:

### Simple Answer:
You get organization keys and workspace keys from **Ops Center** - Tyler's operational portal for managing organizations, workspaces, products, and deployments.

### Technical Details:

**What are these keys?**
- **OrganizationKey**: A unique identifier for a customer organization, required in Identity Gateway authorization requests to route users to their organization's Identity Provider
- **WorkspaceKey**: A unique identifier for a specific workspace within an organization, used for workspace-based authentication

**How to obtain them:**

1. **Access Ops Center** - Tyler's operational portal
2. Navigate to the organization or workspace you need keys for
3. The keys will be displayed in the organization/workspace details

**When you need them:**
- **Workforce applications**: Need `organizationKey` parameter in authorization requests to the Identity Gateway
- **Multi-tenant applications**: Need to retrieve keys for each customer organization
- **Workspace-specific routing**: Use `workspaceKey` (preferred over organizationKey when available)

**In your code**, you'll pass these as parameters:
```javascript
// Workforce - using organizationKey
&organizationKey={orgKey}

// Or preferably, using workspaceKey
&workspaceKey={workspaceKey}
```

For more detailed information, you can visit the Identity documentation at: https://docs.tylerdev.io/identity
