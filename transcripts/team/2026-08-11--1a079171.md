```markdown
Based on the Ops Center documentation, here's what's available via the Ops Center client:

## Main Features & Sections

### **Dashboard**
The dashboard is your starting point and provides:
- Links to various Ops Center sections
- Links to external Ops tools
- Quick access to common ops tasks

### **Core Management Areas**

1. **Organizations**
   - Listing of organizations and their details
   - Manage organization information
   - Add Org Admins or self-promote as Org Admin

2. **Products**
   - Listing of products that can be licensed
   - Product Ops Apps
   - Product registration information
   - License and activate products
   - Bulk Licensing capabilities

3. **Systems**
   - Listing of Tyler systems serving client-facing functionality

4. **Workspaces**
   - Manage workspaces within organizations

### **Common Operations**

- **Client Admin Center access request** - Request access to an organization's Admin Center for yourself or for a client IT admin
- **New Organization request** - For product deployment/implementation teams to request a new organization
- **Community Access Profile Manager (CAPM) access request** - Request CAPM access for Tyler staff to troubleshoot community resident accounts
- **Manage Tyler Ops users** - Promote teammates (in non-prod environments)

### **Identity & Federation Features**
- Setup/Reset AD Agent User Account (with proper permissions)
- Reestablish Federation (with proper permissions)

### **Additional Capabilities**
- Telemetry monitoring
- Bulk licensing operations
- API access for automation and integration
```
