> With the api is there a wayto find what workspaces have a product licensed?

**A:**

Yes! There are multiple ways to find which workspaces have a product licensed using the API:

## Option 1: TCP Search API (Recommended for Bulk Queries)

Use the **TCP Search API** to search for workspaces. While the documentation doesn't explicitly show a filter by product, you can:

**POST** `{BASE_URL}/platform/search/api/v1/Search/workspaces`

This returns workspace documents that you can then filter by examining the response fields. Each workspace document in the response will include licensed and available products.

## Option 2: Provisioning Service v2 API

For individual workspace lookups, use:

**GET** `{BASE_URL}/portal/provisioning/api/v2/Tenants/{urlPrefix}`

This returns `TenantData` which includes:
- **`licensedProductRegistrationIds`** - Array of product registration IDs licensed to this workspace
- **`availableProductRegistrationIds`** - Array of product registration IDs available on this workspace

### Example Response Fields:
```json
{
  "urlPrefix": "cityofmobileal-test",
  "agencyTitle": "City of Mobile [Test]",
  "customerId": "cityofmobileal",
  "licensedProductRegistrationIds": ["financials-erp", "permitting"],
  "availableProductRegistrationIds": ["financials-erp", "permitting"]
}
```

## Option 3: Query by Organization

To find all workspaces under an organization:

**GET** `{BASE_URL}/portal/provisioning/api/v2/Tenants?customerId={orgKey}`

This returns all workspaces for that organization, each with their `licensedProductRegistrationIds` and `availableProductRegistrationIds`.

## Authentication

All endpoints require a **JWT bearer token** with appropriate scopes:
- `tyler-cloud-platform-api-access` for Search API
- `read:workspace` for Provisioning API workspace lookups

## Note on Licensing vs Availability

Remember that Ops Center uses a two-stage model:
- **Licensing** = Organization-level entitlement
- **Availability** = Workspace-level activation

A workspace's `licensedProductRegistrationIds` shows what the organization is entitled to, while `availableProductRegistrationIds` shows what's actually activated on that specific workspace.

**Q:**

> Is there a way to find all orgs that have a particular product license?

**A:**

```markdown
Let me search for information about finding organizations by product license using the API.

Based on the knowledge base, there isn't a direct API endpoint to filter organizations by a specific product license. However, there are **several approaches** you can use:

## Approach 1: Iterate Through Organizations (API Method)

You'll need to query each organization individually to check their licensed products:

1. **Get all organizations** using the TCP Search API:
   ```
   POST {BASE_URL}/platform/search/api/v1/Search/organizations
   ```

2. **For each organization**, get their licensed products:
   ```
   GET {BASE_URL}/portal/provisioning/api/v2/Organization/{organizationId}/products
   ```
   
   This returns `PagedOrganizationProducts` with the list of products licensed to that org.

**Note:** The `{organizationId}` is the **internal numeric Organization ID**, not the organization key (`customerId`). You'll need to map between them.

## Approach 2: Use Webhooks for Real-Time Tracking

Subscribe to product licensing events via the **TCP Webhook API**:

- **Event type**: `TCP.Webhook.Messages.V1.ProductLicensed`
- **Filter fields**: `ProductRegistrationId`, `OrganizationKey`

You can filter the webhook subscription to only receive events for a specific product, allowing you to maintain your own list of organizations with that product.

## Approach 3: AWS QuickSight Dashboard (Reporting/Analytics)

For **production (tylerportico.com)** data, use the **TCP Prod Stats** QuickSight dashboard:

**Dashboard URL**: https://us-east-1.quicksight.aws.amazon.com/sn/dashboards/b10d73d5-06b6-4b74-8df4-6a15d4eaf8b6

The **Products** section includes:
- **Org Count By Product Licensed** - Shows how many orgs have each product
- **Product Licensing Info** - Downloadable data (CSV/Excel export available)

### Access via Tyler SSO:
1. Go to https://sso.tylertech.com/app/UserHome
2. Click **Tyler Cloud Insights Center**
3. Find the **TCP Prod Stats** dashboard

This dashboard provides telemetry on Organizations, Workspaces, and Product licensing, and you can export the data for analysis.

## Approach 4: Ops Center UI (Manual)

In the Ops Center UI:
1. Navigate to **Product Registry**
2. Find your product
3. View **"Orgs with product licensed"** count and **"Workspaces with product activated"** count

However, this doesn't provide a downloadable list of specific organizations.

## Recommendation

For programmatic access, **Approach 1** (iterating through organizations) is currently the most direct API method, though it requires multiple API calls. For reporting and analytics on production data, **Approach 3** (QuickSight dashboard) provides exportable data without custom coding.
