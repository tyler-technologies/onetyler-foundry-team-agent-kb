Based on the knowledge base, here's information about **Workforce Delegated**:

## What is Workforce Delegated?

**Workforce Delegated** is a special variant of Workforce Direct that delegates identity and user setup to another organization (the "Super") it depends on. Organizations using this setup are called "Sub" orgs.

### Key Characteristics:

- **Identity Management**: Only the Super org can set up federations and add users
- **User Addition**: Sub orgs can only add users that already exist in the Super org
- **Solution Independence**: Both Super and Sub orgs can have their own solutions and grant access independently
- **User Deletion**: 
  - Deleting a user in the Super removes them from all Sub orgs
  - Deleting in a Sub only affects that specific Sub org

### When to Use Workforce Delegated:

This setup is appropriate for special cases where:
- Software is installed in multiple sub-organizations with identity/users maintained at a higher super org
- Examples include:
  - **School district + schools** (district has a global email domain across multiple schools)
  - **City + dependent departments** (city across its police, fire, etc.)

### Important Note:

When only 1–2 sub-orgs are involved and the Super isn't administering any Tyler solutions, **Workforce Direct with separate federations is preferred** over Workforce Delegated.

## Setting Up Workforce Delegated:

When importing or creating an organization in Ops Center, you can select Workforce Delegated as the Identity Setup option and then select an existing Super org (which must not itself be Workforce Delegated).
