## Why Magic Links Might Be Invalid

While the documentation doesn't explicitly list all reasons magic links become invalid, the key issue identified is:

### **Email Domain Blocking**

Magic link emails may not reach recipients if the customer hasn't **allow-listed Tyler email domains**. Customers need to allow-list:

- **`tylerportico.com`** (for any org)
- **`Okta.com`** (additional requirement for Workforce Managed orgs — magic-link emails come from Okta as well)

If these domains are blocked by the customer's email filters or firewall, the magic link emails won't be delivered, making the links effectively invalid/unusable.

### **When Magic Links Are Sent**

Magic links are typically sent when:
- Creating a new organization and selecting "Send magic link on org creation"
- Adding an Org Admin with the magic link option enabled
- Using "Setup new federation" under Identity Workforce

### **Important Note for Workforce Delegated Orgs**

Magic links do **not** apply if you selected **Workforce Delegated** identity setup. In this case, the specified Org Admin will be added to the Super org instead.
