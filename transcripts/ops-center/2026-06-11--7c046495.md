**Q:**

> Is there an api that will tell me what products are regisitered for a org/workspace?

**A:**

```markdown
I'll search the knowledge base for information about APIs that can retrieve registered products for an organization or workspace.

Yes! There is an API that will tell you what products are registered for an organization/workspace. Here's what you need to know:

## API Endpoint

**GET** `/api/v2/Tenants/{urlPrefix}`

This endpoint returns tenant data that includes the products registered for a workspace.

## Response Fields

The `TenantData` response includes these key fields for products:

| Field | Type | Description |
|-------|------|-------------|
| `licensedProductRegistrationIds` | string[] | Registration IDs of products **licensed** to the workspace's organization |
| `availableProductRegistrationIds` | string[] | Registration IDs of products **available** (activated) on the specific workspace |

## Important Distinction

- **Licensed Products** (`licensedProductRegistrationIds`) - Products the organization is **eligible** to use (org-level)
- **Available Products** (`availableProductRegistrationIds`) - Products actually **enabled** on that specific workspace (workspace-level)

A product must be licensed to the organization AND made available on a workspace for it to be functional.

## Additional Endpoints

For managing product availability on a workspace:
- **PUT** `/api/v2/Tenants/{urlPrefix}/products/by-registrationid` - Set which products are available on a workspace (preferred)
- **PUT** `/api/v2/Tenants/{urlPrefix}/products/by-name` - Legacy variant (retained for backward compatibility)
```
