## What is a Workspace?

A **Workspace** is a consistent **logical construct** that groups Tyler solutions together, regardless of each solution's hosting environment. Here are the key points:

### Core Definition
- A **cloud environment** for Tyler solutions (Production or NonProduction)
- Associated **1:1 with a tenant** (a technical construct that virtually segregates data/config on shared infrastructure)
- Represents a "customer business purpose"

### Key Characteristics
- **Provisioned by Tyler** — customers cannot create new workspaces themselves through Admin Center
- Groups Tyler solutions consistently across different hosting environments
- Some platforms (like Tyler Cloud Platform/TCP) can host all of a customer's workspaces (prod/test/train/staging) in one environment with virtual data segregation

### Workspace Components
Within a workspace, you can manage:
- **Access Control Lists (ACLs)** — control who can access what applications
- **Apps** — lists apps that require ACL-based access
- **Links** — customize footer links for community-facing applications
- **Contacts** — set business and technical contacts
- **Banner** — for NonProduction workspaces, set visual banners to distinguish from production

### Identifiers
- Each workspace has a unique **Workspace ID** (`portalId` / `workspaceKey`)
- Has a configurable title that controls Community App Directory banner text and navigation

If you need a new workspace or find one missing, you should contact Tyler Support.
